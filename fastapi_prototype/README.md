# HealthOS-AI FastAPI Research Prototype

This folder adds a Python/FastAPI research prototype to the existing Kaiser-style demo backend without replacing the Express/Mongoose application.

## Research Purpose

The prototype supports dissertation experiments around trustworthy multi-agent healthcare navigation, grounded retrieval, synthetic longitudinal records, transparent prediction baselines, human escalation, and evaluation.

## Included Prototype Capabilities

- Synthetic patient record endpoint
- Rule-based agent orchestrator
- Specialized routing for medical record, medication, appointment, preventive care, and care navigation requests
- Lightweight TF-IDF grounded retrieval over an approved demo knowledge base
- Confidence score and human-review flag
- Transparent no-show-risk baseline
- Explicit research-only safety language

## Run Locally

```bash
cd fastapi_prototype
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Open the autogenerated API docs at `http://localhost:8000/docs`.

## Example

```bash
curl -X POST http://localhost:8000/agent/query \
  -H "Content-Type: application/json" \
  -d '{"patient_id":"SYN-1001","query":"Explain my A1C result and what is due next"}'
```

## Dissertation Evolution Path

1. Replace the embedded demo records with Synthea FHIR R4 ingestion.
2. Replace TF-IDF retrieval with an evaluated vector/graph retrieval layer.
3. Add a formal orchestrator with auditable tool selection and bounded agent permissions.
4. Train/evaluate appointment no-show and personalization models.
5. Add fairness, calibration, hallucination, retrieval, task-completion, and escalation metrics.
6. Compare single-agent, multi-agent, and multi-agent + RAG conditions in controlled experiments.
7. Add human-in-the-loop review and institutional data only after approvals and governance requirements are satisfied.

## Important

This is a research/demo system using synthetic data. It is not affiliated with Kaiser Permanente and is not intended for diagnosis, treatment, emergency triage, or production clinical use.
